                          PROBLÈMES IDENTIFIÉS
================================================================================

1. DOUBLE EXÉCUTION RISQUE
   ─────────────────────────
   Problème:
   • Robot se lance automatiquement à 20h00
   • Admin peut aussi cliquer sur le bouton manuel n'importe quand
   • Si les deux se lancent en même temps → DOUBLE VERROUILLAGE
   
   Impact:
   ├─ Incohérence dans les données
   ├─ Commandes verrouillées 2 fois
   └─ Confusion dans les logs
   
   Scénario dangereux:
   ├─ 20h00:00 → Robot lance le JIT (verrouille commandes)
   ├─ 20h00:15 → Admin clique aussi sur le bouton
   └─ ⚠️ DOUBLE VERROUILLAGE


2. MARGE DE TOLÉRANCE INEXISTANTE
   ───────────────────────────────
   Problème:
   • JIT se lance strictement à 20h00:00 (pas de marge)
   • CronTrigger(hour=20, minute=0, second=0)
   • Si robot est en retard de 2 minutes → job ne s'exécute que demain 20h00
   
   Cas réel:
   ├─ 20h00:02 → Robot ne lance rien (trop tard)
   ├─ Attendre 24h pour le prochain essai
   └─ Perte d'une journée d'agrégation


3. COMMANDES VERROUILLÉES PERMANENTES?
   ────────────────────────────────────
   Problème:
   • Après 20h00, toutes les commandes statut="Verrouillée"
   • Client ne peut plus rien faire
   • Pas de "déverrouillage" prévu après livraison
   
   Questions ouvertes:
   ├─ Après livraison → déverrouille-t-on?
   ├─ Pour la prochaine tournée → créer nouvelles commandes?
   └─ Management des cycles jour/nuit?
