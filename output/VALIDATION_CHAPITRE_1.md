# Validation du Chapitre 1

## Points conformes

- La table des matières définit clairement le contexte, la problématique, la solution et les objectifs.
- L’introduction générale présente correctement l’orientation AgriTech et l’architecture globale.
- Les technologies principales citées — FastAPI, Next.js/React et React Native/Expo — sont présentes dans le dépôt.

## Points à corriger

- Le chapitre 1 ne contenait aucun développement après sa page de titre.
- Les résultats financiers (« point mort à 7 commandes », marge de 13,5 %) n’étaient pas prouvés par des données d’exploitation.
- Le paiement CMI était présenté comme disponible alors que l’option est désactivée dans le checkout.
- Le rôle respectif de Gemini et de Gemma-2 devait être clarifié.

## Recommandations

- Appuyer le contexte sectoriel sur des sources officielles récentes.
- Présenter les chiffres financiers comme des hypothèses jusqu’à validation terrain.
- Générer les diagrammes à partir du code et insérer des captures réelles de l’application.
- Conserver une distinction explicite entre fonctionnalité implémentée, configuration externe et perspective.
