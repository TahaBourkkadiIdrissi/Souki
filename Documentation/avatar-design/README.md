## 📋 Checklists Rapides

### Avant de Commencer le Design
```
✅ Lire AVATAR_CONCEPTS.md pour comprendre pourquoi Récolte
✅ Lire AVATAR_DESIGN_SYSTEM.md pour palette & proportions exactes
✅ Ouvrir Figma avec template initial (si fourni)
✅ Valider couleurs HEX avec brand manager
```

### Avant d'Exporter Assets
```
✅ Dimensions exactes confirmées (256, 512, 1024 px)
✅ Couleurs exactes (HEX: #E74C3C, #4CAF50, etc.)
✅ Transparence OK (PNG-32 avec alpha)
✅ Taille fichier < limites (SVG 50KB, PNG 150KB)
✅ Métadonnées supprimées (optimiser)
✅ Format de sortie correct (SVG, PNG, WebP, Lottie JSON)
```

### Avant de Coder
```
✅ Fichiers SVG/PNG validés dans /public/avatar/
✅ Fichiers Lottie JSON validés (lottie.io/preview)
✅ React 18+ disponible (Avatar.tsx utilise hooks)
✅ lottie-web installé (npm install lottie-web)
✅ Tailwind CSS configuré (pour styles)
```

### Avant de Déployer
```
✅ Lighthouse performance ≥ 90
✅ CLS < 0.1, LCP < 2.5s
✅ WCAG AA accessibility (0 errors)
✅ Tests cross-browser passés
✅ Mobile responsive OK (64-1024 px)
✅ Fallback PNG fonctionne
✅ prefers-reduced-motion respecté
```

## 🚀 Getting Started Paths

### Path 1: "Je dois décider rapidement"
```
Durée: 30 min
1. EXECUTIVE_SUMMARY.md         (15 min) ← Business overview
2. AVATAR_CONCEPTS.md          (10 min) ← Why Récolte?
3. Video pitch (optionnel)       (5 min)
→ Take decision & move forward
```

### Path 2: "Je dois designer Récolte"
```
Durée: 2-3 hours
1. AVATAR_DESIGN_SYSTEM.md      (30 min) ← Learn specs
2. AVATAR_MASCOTTE_CHARTER.md   (30 min) ← Learn personality
3. Créer/affiner design Figma   (1.5-2h) ← Make it real
4. AVATAR_ANIMATIONS.md         (20 min) ← Understand animations
→ Livrer assets finalisés
```

### Path 3: "Je dois animer Récolte"
```
Durée: 2-3 days
1. AVATAR_DESIGN_SYSTEM.md      (15 min) ← Visual specs
2. AVATAR_ANIMATIONS.md         (60 min) ← Animation specs (lire en détail)
3. AVATAR_MASCOTTE_CHARTER.md   (20 min) ← Understand emotional cues
4. Créer 11 Lottie animations   (2-3 days) ← Make it happen
5. Optimisation & validation    (4 hours) ← Test & compress
→ Livrer fichiers Lottie < 100 KB
```

### Path 4: "Je dois intégrer Récolte"
```
Durée: 1-2 days
1. AVATAR_INTEGRATION_GUIDE.md  (60 min) ← Code ready-to-use
2. AVATAR_TECHNICAL_SPECS.md    (30 min) ← Tech requirements
3. Setup projet & assets        (1-2 hours) ← Copy/install
4. Intégrer composant React     (2-4 hours) ← Implement
5. Tests & validation           (2-3 hours) ← Verify
→ Avatar fonctionnel en production
```

### Path 5: "Je dois vérifier la qualité"
```
Durée: 3-4 hours
1. AVATAR_TECHNICAL_SPECS.md    (30 min) ← QA checklist
2. Lighthouse audit             (30 min)
3. Browser testing              (1-2 hours)
4. Accessibility audit (WCAG)   (1 hour)
5. Mobile responsive test       (30 min)
→ QA complete, ready to ship
```
