# Logos

Logos SOUKI repris tels quels de `apps/mobile/assets/brand`. Ne pas redessiner, recolorer ni déformer.

- `horizontal.png` : logo complet, sur fond clair.
- `symbol.png` : le symbole seul.
- `splash-symbol.png` : le sac blanc et la feuille, base de l'écran de démarrage et de l'icône adaptative, sur `#005B43`.
- `app-icon-1024.png` : icône de l'app iOS, référence pour l'icône Play.
