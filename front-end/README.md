# Souki Front-End

Projet Next.js configuré pour le front-end de Souki.

## Scripts

- `npm run dev` : démarre le serveur de développement
- `npm run build` : génère l'application pour la production
- `npm run start` : lance l'application en mode production
- `npm run lint` : exécute ESLint

## Prérequis

- Node.js 18+ recommandé
- npm

## Démarrage

1. `cd front-end`
2. `npm install`
3. `npm run dev`
